# 🚢 Surviving the Titanic

> **Exploring the people, patterns, and circumstances behind Titanic survival.**

## 📖 About

**Surviving the Titanic** is an interactive Power BI dashboard exploring passenger survival during the Titanic disaster of **April 15, 1912**.

The analysis uses passenger-level attributes such as **sex, age, passenger class, fare, family relationships, embarkation port, and country** to uncover patterns between survivors and non-survivors.

## 📊 Dataset

The dashboard is built around the following passenger attributes:

* **Passenger:** ID, Name, Country
* **Demographics:** Sex, Age
* **Travel:** Class, Ticket, Fare
* **Journey:** Embarkation Port
* **Outcome:** Survived

## 🔎 What the Dashboard Explores

* Overall **survival vs. non-survival**
* Survival patterns by **sex and age**
* Differences across **passenger classes**
* Relationship between **fare and survival**
* Impact of **family connections**
* Individual **passenger-level details**

## 🛠️ Built With

**Power BI · DAX · Power Query · Deneb (Vega/Vega-Lite)**

The dashboard combines standard Power BI analytics with custom **Deneb visualizations** to create a more engaging data-storytelling experience.
